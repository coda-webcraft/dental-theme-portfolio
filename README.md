# dental-theme-portfolio（静的公開版）

WordPressオリジナルテーマ「[dental-theme](https://github.com/coda-webcraft/dental-theme)」を、Simply Staticで静的HTML化し、GitHub Pagesで公開するためのリポジトリです。

## 公開URL

https://coda-webcraft.github.io/dental-theme-portfolio/

## このリポジトリについて

- テーマ本体のソースコード（PHP・ACF・Sass等）は [dental-theme](https://github.com/coda-webcraft/dental-theme) リポジトリで管理しています。実装内容はそちらをご確認ください。
- 本リポジトリの中身は、Simply Staticによって書き出された静的HTML・CSS・JS・画像ファイル一式です。
- 静的化の都合上、お問い合わせ・ご予約フォームの送信処理などPHPによる動的な機能は本サイトでは動作しません（画面・機能の構成はご確認いただけます）。
